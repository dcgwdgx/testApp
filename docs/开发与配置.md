# 开发与配置

## 环境要求

- Node.js 20 或与当前 Expo SDK 54 兼容的版本。
- npm。
- Android Studio、Android SDK 和可用的模拟器或真机，用于 Android 开发。
- macOS、Xcode 和有效的 Apple 开发凭据，用于 iOS 本地构建。
- Expo 账号和 `EXPO_TOKEN`，用于 EAS 构建与提交。
- 火山引擎 Ark API 密钥。

## 首次安装

```powershell
Copy-Item .env.example .env
npm ci
```

编辑 `.env`：

```dotenv
ARK_API_KEY=你的真实密钥
```

`.env` 已被 Git 忽略。不要把真实密钥写入 README、Issue、日志、截图或提交记录。

## 启动项目

```powershell
npm start
```

也可以直接选择平台：

```powershell
npm run android
npm run ios
npm run web
```

`react-native-iap` 属于原生模块。需要验证真实内购时，应使用开发构建、预览构建或商店安装包；仅使用 Expo Go 不能完整验证内购行为。

## 环境变量与应用配置

`app.config.js` 读取以下变量：

| 变量 | 用途 | 未设置时的行为 |
| --- | --- | --- |
| `ARK_API_KEY` | 调用火山引擎图像生成接口 | 使用占位字符串，生成会失败 |
| `ANDROID_VERSION_CODE` | Android 内部版本号 | 使用 `1` |
| `IOS_BUILD_NUMBER` | iOS 构建号 | 使用 `1` |

应用标识：

- Expo slug：`pet-portrait-ai`。
- URL scheme：`pet-portrait-ai`。
- Android 包名：`com.petportrait.ai`。
- iOS Bundle ID：`com.petportrait.ai`。
- EAS 项目 ID：`6d571e25-fac4-4864-9e9c-cf2d93448e98`。

## 类型检查

```powershell
npm run typecheck
```

项目当前没有配置 ESLint、单元测试或端到端测试命令。每次提交至少应通过类型检查，并按[测试清单](测试清单.md)完成关键路径验证。

## 图片权限

- 用户上传图片通过系统图片选择器完成。
- Android 明确阻止旧的外部存储和媒体读取权限，避免申请不必要的广泛访问权限。
- 保存结果时通过 `expo-media-library` 请求写入相册所需权限。
- iOS 权限说明配置在 `app.config.js` 的 `infoPlist` 和 Expo 插件设置中。

## 常见问题

### 生成接口返回 401 或 403

检查 `.env` 中的 `ARK_API_KEY` 是否有效，并重新启动 Expo 开发服务器，使配置重新载入。

### 生成超时

单次请求超时为 120 秒，最多重试 2 次；生成页面另有 180 秒兜底计时。检查网络、火山引擎额度和模型可用性。

### 商品没有显示本地价格

确认当前构建连接到了正确的 App Store 或 Google Play 测试环境，并确认三个商品 ID 与商店后台完全一致。商店信息不可用时，应用会显示代码中的美元备用价格。

### Web 端无法购买

这是当前设计：Web 端会直接提示购买仅在移动应用中可用。

### 本地 Git 显示 `ahead 3`

先刷新远端跟踪引用再判断是否需要推送。GitHub `master` 已包含 `567f097`、`911fd34` 和 `fb03279`，不要为了清除旧的本地状态而制造重复提交。
