# 测试清单

项目目前没有自动化测试套件。以下清单用于每次发布前的人工回归；至少在一个 Android 真机和一个 iOS 真机或 TestFlight 构建上执行。

## 基础检查

- [ ] `npm ci` 能成功安装依赖。
- [ ] `npm run typecheck` 无错误。
- [ ] 应用冷启动和再次启动都不崩溃。
- [ ] 首页显示 24 个设计、1 次免费体验和约 60 秒生成提示。
- [ ] 页面返回、滚动、安全区和横向风格选择正常。
- [ ] 无真实密钥、服务账号或证书出现在 Git 变更中。

## 图片选择与权限

- [ ] 首次选择照片时出现正确的系统权限或图片选择器。
- [ ] 拒绝权限后应用不崩溃，并能再次尝试。
- [ ] 取消图片选择不会显示错误弹窗。
- [ ] 支持选择常见 JPEG、PNG 和手机照片。
- [ ] 图片可裁剪为正方形，预览不变形。
- [ ] Android 未申请不必要的广泛媒体读取权限。

## 生成流程

- [ ] 未选择图片时不能生成。
- [ ] 未选择风格时按钮保持不可用。
- [ ] 24 个设计和所有分类都可访问。
- [ ] 风格强度滑块可调整且不会卡住页面。
- [ ] 第一次生成不要求购买。
- [ ] 生成中显示状态并允许取消。
- [ ] 网络错误、无效密钥、额度不足和超时会显示可理解的错误。
- [ ] 失败或取消不会扣除免费次数或积分。
- [ ] 成功后只扣除一次免费次数或一个积分。
- [ ] 成功结果能进入结果页，并写入历史。

## 结果、保存与分享

- [ ] 结果、原图和对比三个视图显示正确。
- [ ] 对比滑块可拖动，边界正常。
- [ ] 分享可以打开系统分享面板。
- [ ] 保存时正确请求相册权限。
- [ ] 拒绝保存权限后能打开系统设置或取消。
- [ ] 保存成功后相册中存在可打开的 JPEG。
- [ ] “尝试其他风格”和“新照片”返回路径正确。

## 历史记录

- [ ] 新结果出现在列表顶部。
- [ ] 点击历史记录可以重新查看结果。
- [ ] 长按可以删除单条记录。
- [ ] “全部清除”有确认提示并能清空。
- [ ] 超过 10 次生成后只保留最近 10 条。
- [ ] 清除应用数据或卸载后历史消失，符合当前设计。

## 免费次数与内购

- [ ] 新安装只有 1 次免费生成机会。
- [ ] 免费机会用完且积分为 0 时显示付费墙。
- [ ] 三个商品 ID 都能从商店加载。
- [ ] 显示商店返回的本地化价格，而不是错误币种或空价格。
- [ ] 取消购买不会提示为系统故障。
- [ ] 待处理交易不会提前发放积分。
- [ ] 成功购买后增加正确的 10、30 或 60 积分。
- [ ] 同一交易回调多次时只发放一次积分。
- [ ] 每次成功生成只扣除 1 个积分。
- [ ] Web 端明确提示内购只在移动应用可用。

## 隐私与数据说明

- [ ] 应用内隐私政策、`privacy.html` 和商店数据安全声明内容一致。
- [ ] 明确说明宠物照片会发送到火山引擎处理。
- [ ] 明确说明历史、积分和有限产品事件保存在本机。
- [ ] 联系邮箱可用。
- [ ] 应用实际权限与商店申报一致。

## 商店与发布

- [ ] 应用名称、短说明和完整说明与当前功能一致。
- [ ] 文案准确写明 24 个设计、1 次免费体验和一次性积分包。
- [ ] 没有把积分包描述成订阅。
- [ ] 5 张截图顺序正确、文字可读、无裁切。
- [ ] 手机、7 英寸和 10 英寸平板区域均已设置所需截图。
- [ ] 置顶大图为 1024×500。
- [ ] AI 生成或编辑的素材已完成声明。
- [ ] 如果添加视频，YouTube 地址可访问、无广告、无年龄限制。
- [ ] 发布概览中只包含本次预期变更。
- [ ] 审核通过后在公开商店页面再次核对。

## 发布结果记录

每次发布完成后，在 `docs/构建发布与商店.md` 记录：

- 提交日期和平台。
- 应用版本与构建号。
- 提交的代码 commit。
- 商店轨道或 TestFlight 状态。
- 商品详情是否变更。
- 已知问题、审核结果和必要的回滚说明。
